This entry writes one sentence pitching a startup that sells sealed jars of
air collected in a customer's childhood hometown to homesick expats living
far away. It sounds like selling literal nothing, but the logic holds: the
jar is a tangible piece of home, nostalgia is a proven market (souvenirs,
comfort food, hometown snacks all sell on the same feeling), and at $29 a jar
it is a cheap emotional purchase next to a $900 flight home — a product
nobody returns because you cannot return a memory.

Run `python3 main.py` and the pitch is written to `/output/entry.txt`.
